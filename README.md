# Spearpoint AI

An employer workspace for confidential senior hiring.

## Workflow

Create an account, add your company name, describe the role and review the AI-drafted hiring brief. Compare anonymised candidate summaries in a table, save profiles, add private notes and request a specialist introduction.

The main onboarding flow requires no niche or sector selection. Additional context and search refinements are optional. Public-profile research is reviewed before candidate summaries are displayed.

## Development

Requires Node.js 22 or newer.

- `npm test`: run automated checks.
- `npm run check`: check source syntax.
- `npm run dev`: start the development server with the required configuration.

Keep credentials and private candidate information out of source control.
